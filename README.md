# 🔬 التحليل اللغوي المجهري — مختبر تحليل السور والآيات

منصة تعليمية تفاعلية (ملف HTML واحد، يعمل دون خادم أو إنترنت*) لتحليل سور وآيات القرآن الكريم لغويًا، موجّهة للأطفال والمعلمين.

**المحتوى:** 30 ورقة عمل (20 سورة + 10 آيات مختارة) · 1,780 سؤالًا · تصحيح تلقائي لـ 1,316 سؤالًا · و1,643 سؤالًا لها إجابة أو إجابة نموذجية، والباقي أنشطة (رسم وقراءة وترديد).

\* تُحمَّل الخطوط من Google Fonts عند توفر الإنترنت، ويعمل الموقع بخط النظام بدونها.

| للمعلّم — معلومات سريعة | |
| --- | --- |
| **تشغيل المشروع** | `./run.sh` |
| **فتح صفحة المدير** | ٥ نقرات على الشعار · أو `Ctrl+Alt+A` · أو `#admin` |
| **كلمة مرور المدير** | `mijhar1447` |

## ✨ الميزات
- بطاقات قابلة للفتح لكل ورقة (تعمل حتى مع تعطيل JavaScript — HTML أصلي `<details>`).
- **موقع كل سورة**: يظهر رقم السورة في المصحف وعدد آياتها، ورقم الآية وسورتها لأوراق الآيات المختارة.
- **أرقام الآيات داخل علامة ۝** في نص كل ورقة، مع مراعاة المقاطع غير المتتابعة (مثلًا التكوير: ١-٦ ثم ١٩ و ٢٠).
- حقول ذكية حسب نوع السؤال:
  - **تقسيم الكلمات**: كتابة الحروف تُدرِج فاصل `+` تلقائيًا (فلق ← ف + ل + ق).
  - **الأسئلة العددية**: تقبل الأرقام العربية (٥) والإنجليزية (5).
  - **النسخ/الإملاء/الدمج/الترتيب**: مقارنة تتجاهل التشكيل وفروق الهمزات.
  - **الاستخراج**: تحقق من وجود الكلمة في السورة ومطابقتها للظاهرة (شدّة، تنوين، لام شمسية، تاء مربوطة، ألف مقصورة...).
- **إجابة لكل سؤال**: ما يمكن حسابه من نص الآية يُصحَّح آليًا، وما يحتاج فهمًا وتدبرًا له إجابة نموذجية تظهر بزر «إظهار الإجابة النموذجية»، وما تبقّى أنشطة أداء تُعلَّم بعلامة ✓.
- **مستوى صعوبة لكل سؤال**: بسيط · سهل · متوسط · صعب · صعب جدًا، مع شريط بتوزيع المستويات في رأس كل ورقة.
- **بيانات الباحث عامة**: الاسم والتاريخ والمستوى والدرجة تُكتب مرة واحدة فتنطبق على كل الأوراق وتُحفظ في المتصفح وتظهر عند الطباعة.
- تغذية راجعة فورية: ✓ أخضر للصحيح، ✗ أحمر للخطأ مع زر «إظهار الإجابة الصحيحة».
- عدّاد تقدّم ودرجات لكل ورقة، وبحث وتصفية (سور/آيات).
- طباعة أي ورقة بتنسيق نظيف مطابق للأوراق الأصلية.

## 📱 العرض على الجوال والحاسب
تصميم متجاوب واحد يخدم الشاشات كلها:
- **الحاسب**: الورقة المفتوحة تتمدّد على عرض الشبكة كاملًا (٩٦٠ بكسل مركزية، والأسئلة بعمودين)، وتتوسّع الحاوية إلى ١٣٤٠ بكسل على الشاشات العريضة (≥١٥٠٠).
- **الجوال**: عمود واحد للبطاقات والأسئلة، الورقة بعرض الشاشة، الإحصائيات في شبكة ٢×٢، وشريط البحث والتصفية بعرض كامل.
- **شريط أدوات لاصق** لكل ورقة (إغلاق · تفريغ · طباعة) يبقى ظاهرًا أثناء التمرير، ويُحسب موضعه من ارتفاع الشريط العلوي الفعلي.
- أهداف لمس ٤٤ بكسل على شاشات اللمس، وحقول بحجم ١٦ بكسل حتى لا يُكبّر iOS الصفحة عند الكتابة.
- مراعاة الحواف المنحنية (`safe-area`)، والوضع الأفقي للجوال، وتقليل الحركة (`prefers-reduced-motion`)، والتكبير باللمس متاح دائمًا.
- الطباعة تعمل من الحاسب والجوال (تُطبع الورقة المفتوحة فقط).

## 🚀 التشغيل
```bash
./run.sh              # بناء + خادم محلي + فتح المتصفح (المنفذ 8080)
./run.sh --port=3000  # منفذ آخر
./run.sh --no-open    # بلا فتح المتصفح
npm start             # مثل ./run.sh
npm run serve         # خادم فقط دون إعادة بناء
```
يطبع الخادم رابطين: واحد للحاسب (`localhost`) وآخر بعنوان الجهاز على الشبكة لتجربة الموقع من الجوال على نفس شبكة الواي فاي. ويمكن أيضًا فتح `dist/index.html` مباشرة بالمتصفح دون خادم.

## 🛠️ صفحة المدير (مخفية + كلمة مرور)
لا يوجد زر ظاهر للصفحة. تُفتح بإحدى ثلاث طرق:

| الطريقة | كيف |
| --- | --- |
| ٥ نقرات على الشعار | اضغط شعار الموقع أعلى اليمين ٥ مرات متتابعة (يعمل باللمس) |
| اختصار لوحة المفاتيح | `Ctrl + Alt + A` (أو `Cmd + Alt + A`) |
| الرابط المباشر | أضف `#admin` إلى عنوان الصفحة |

ثم تظهر بوابة تطلب كلمة المرور:

### 🔑 كلمة المرور

```
mijhar1447
```

تُكتب بحروف إنجليزية صغيرة دون مسافات، وتُطلب مرة واحدة في كل جلسة متصفح، ويُغلق كل شيء بمفتاح `Esc`.

**لتغيير كلمة المرور:** عدّل السطر التالي في `src/js/admin.js` ثم نفّذ `npm run build`:
```js
var ADMIN_PASS='mijhar1447';   // ← اكتب كلمة المرور الجديدة هنا
```

> ⚠️ **تنبيه:** التحقق يجري في المتصفح، فهو يمنع دخول الأطفال عرضًا ولا يُعدّ حماية أمنية — كلمة المرور قابلة للقراءة من مصدر الصفحة. لا تستخدمها لحماية بيانات حسّاسة.

### الصفحة من خطوتين
**١) إضافة سورة أو آية** — اسم الورقة، النوع (سورة كاملة / آية مختارة)، النص مع زر «۝ إدراج علامة آية»، رقم السورة في المصحف، عدد آياتها، رقم الآية، اللون، وعناوين **الأقسام الثلاثة**. عند الحفظ تظهر الورقة فورًا في الشبكة بأرقام آياتها وموقعها، وتُحفظ في المتصفح.

**٢) إضافة الأسئلة** — تختار الورقة (بما فيها الأوراق التي أضفتها) والقسم (بعناوينه الحقيقية) ونوع السؤال:
- **٣٢ نوع سؤال**: كل الأنواع الأصلية + اختيار من متعدد، صح/خطأ، أكمل الفراغ من الآية، ترتيب حروف مبعثرة، عدّ النقاط، سؤال مفتوح بإجابة نموذجية، مهمة إنجاز ✓، وأنواع إضافية: عدد كلمات السورة، عدد حروفها، رقم السورة في المصحف، عدد آياتها، الكلمة رقم (ن)، أطول كلمة، نوع الـ (شمسية/قمرية)، ومعنى كلمة بإجابة نموذجية.
- **منع التكرار**: يُرفض أي سؤال نصّه موجود في الورقة (أصليًا كان أو مضافًا).
- **تحقق آلي**: الأنواع المرتبطة بالنص تتحقق من السورة وتحسب الإجابة تلقائيًا، ويُحسب مستوى الصعوبة للسؤال المضاف.
- **الحفظ**: تلقائي في المتصفح (localStorage)، وزر «تنزيل نسخة محفوظة» يُصدر ملف HTML جديدًا يضم **الأوراق والأسئلة المضافة** جاهزًا للتوزيع.

## 🧪 البناء والاختبار
```bash
npm install                 # مرة واحدة (jsdom للاختبار فقط)
npm run build               # يولّد dist/index.html
npm test                    # المحتوى، التصحيح، التجاوب، المستويات، وصفحة المدير
node tools/inspect.js       # ملخص التصحيح الآلي لكل ورقة
node tools/inspect.js ikhlas   # أسئلة ورقة معيّنة وإجاباتها المحسوبة
```
المطلوب: Node.js 18 أو أحدث. و`run.sh` يجد Node تلقائيًا في `~/.local/node` أو `nvm` إن لم يكن في `PATH`، ويثبّت التبعيات عند أول تشغيل.

## ➕ إضافة ورقة عمل جديدة
**من صفحة المدير** (الأسهل): الخطوة الأولى ثم الثانية، وزر «تنزيل نسخة محفوظة» لتثبيتها في ملف التوزيع.

**أو من المصدر**: أضف كائنًا إلى `src/data/worksheets.json` بالحقول:
`id, cat (surah|ayah), hue, name, lab, info, verse (بفواصل ۝), footV, footM, secs[{t, q[]}]`
ثم سجّل رقم السورة في `SURA_NO` وعدد آياتها في `AYAT` داخل `build.js` (وللآيات: `SURA_OF` و`AYA_NUM`)، ثم `npm run build`.
المصنّف يكتشف نوع كل سؤال ويحسب إجابته ومستوى صعوبته من نص الآية تلقائيًا.
